# IAGuardian Shift - overview

> **DRAFT / ROADMAP.** This describes intent, not a finished product. It makes no profit or income claims. Testnet and paper only.

## The idea in plain English
IAGuardian Shift is a planned part of the LTR project that lets people **train and improve** IAGuardian research agents with safe, simulated practice. Any later step beyond simulation would need a person's explicit decision and a hard loss cap, and is not part of this repo.

## Planned stages

| Stage | What happens | Status |
|---|---|---|
| 1. Read | Agents read public data and write cited notes | Pattern described in [`../Agents/`](../Agents/README.md) |
| 2. Paper | Simulated decisions, written to a journal and reviewed | Pattern described |
| 3. Notify | Read-only alerts sent to a human | See [`signals-and-notifications.md`](signals-and-notifications.md) |
| 4. Human-signed testnet trials | A person signs on a test network, with no value at stake | Roadmap |
| 5. Anything with real money | Outside this repo. Needs the owner's explicit approval, a hard loss cap, and professional advice | Not planned here |
