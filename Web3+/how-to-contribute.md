# How to contribute to Web3+

1. Read the risk warning in [`README.md`](README.md).
2. Open an issue with the **Research contribution** template.
3. Write your guide with the front-matter from [`../ATTRIBUTION.md`](../ATTRIBUTION.md).
4. Cite every source and mark AI assistance.
5. Keep it **testnet-only** and **educational**.
6. Run through the safety checklist in [`../CONTRIBUTING.md`](../CONTRIBUTING.md).

## What will be declined

- Anything with private keys, seed phrases, API keys, or tokens
- Code that signs transactions or stores keys
- Profit, income, or return claims
- Instructions that present buying a token on a main network as an investment
- Unlicensed third-party code
