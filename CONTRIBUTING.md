# Contributing to LTResearch

Thank you for helping. Keep it small, sourced, and safe.

## Before you start

- Read [`README.md`](README.md) and [`ATTRIBUTION.md`](ATTRIBUTION.md).
- Testnet only. Paper mode only. Educational only.

## Steps

1. **Open an issue** with the *Research contribution* template. Say what you want to add or fix.
2. **Pick the right folder:** `Agents/`, `Skills/`, or `Web3+/`.
3. **Use the front-matter** from `ATTRIBUTION.md` at the top of new files.
4. **Cite every source** and mark AI assistance (`ai-assisted: yes/no/partial`).
5. **Open a pull request.** Describe what changed and how you checked it.

## Publicly safe checklist

- [ ] No private keys, seed phrases, API keys, or tokens
- [ ] No wallet addresses tied to real funds
- [ ] No private file paths or internal IDs
- [ ] No copied third-party code without license and credit
- [ ] No profit, income, or return claims
- [ ] Anything unchecked is labeled **unverified**
- [ ] Anything unfinished is labeled **DRAFT**

## Rules for trading or signal ideas

- Paper mode by default.
- Notifications only. A human decides and signs every real action.
- No code that signs transactions or stores keys belongs in this repo.
- A hard loss cap must be part of any live-test proposal.

## Brand names

The license does not cover brand names or logos. See [`ATTRIBUTION.md`](ATTRIBUTION.md).
